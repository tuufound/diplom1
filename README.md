

Веб-приложение для планирования задач, проектов, учёта времени и отчётности: Vue 3 (SPA) + Django REST Framework (API) + JWT-аутентификация.

---

## Функциональность (что реализовано)

Технологии:

Frontend: Vue 3, Vite, Vue Router, Pinia, Axios, Bootstrap 5, SCSS, Font Awesome, vue-i18n (RU/EN), date-fns, vue-toastification, jsPDF (экспорт PDF)
BackendЖ Python, Django, Django REST Framework, Simple JWT, SQLite 
Docker Compose (frontend + backend), скрипты доступа по LAN 

Аутентификация и аккаунт:

Регистрация и вход (JWT access + refresh)
Текущий пользователь: получение профиля (GET), обновление имени пользователя (PATCH)
Сброс пароля по связке username + email (публичный endpoint)
Защита маршрутов: гостевые страницы (логин/регистрация/сброс) и приложение только для авторизованных пользователей

Проекты и роли

Проекты: создание, просмотр списка, редактирование названия и описания, удаление (владелец)
Владелец проекта и участники с ролями редактор / наблюдатель
 Приглашение участников по логину и поиск пользователей (автодополнение от 2 символов)
 Удаление участника из проекта (владелец)
 Задачи можно привязывать к проекту или оставлять личными (без проекта)



Задачи

Список задач: поиск по названию/описанию, фильтр по статусу, области «все / совместные / избранное».
Поля задачи: название, описание, статус (к выполнению / в процессе / выполнено / в архиве), приоритет, категория, проект, срок, родительская задача (подзадачи)
Соавторы: приглашение по поиску пользователей; права на редактирование зависят от роли доступа к задаче.
Избранное с переключением на списке и в форме редактирования.
Запуск таймерапо задаче прямо из списка (создаётся запись учёта времени).
Создание / редактирование / удаление задач

 Канбан

Отдельная страница : колонки по статусам, перенос задач между колонками (смена статуса), фильтры «все / совместные / избранное».
Быстрые действия: избранное, сдвиг статуса стрелками, ссылка на список и создание задачи.


Учёт времени

Один активный таймер на пользователя: старт из списка задач, отображение на странице «Время».
Остановка таймера, история записей с датами и длительностью.
Лимит по минутам на активную сессию: опционально звук по истечении, автостоп учёта, предпросмотр звука.
Pomodoro: старт, пауза, сброс; по окончании фазы — звук и смена режима.



Отчёты

Сводка за период (пресеты: день, неделя, месяц, квартал, год, произвольный диапазон дат).
Метрики: всего задач, закрыто, суммарное учтённое время, среднее время (логика на бэкенде).
Распределение задач по статусам, топ задач по времени, список задач за период.
Экспорт: CSV и PDF (таблица задач с колонками задача / статус / приоритет / категория / время).


 Профиль и интерфейс

Карточка профиля: статистика по задачам, недавняя активность (события по задачам и времени).
Редактирование имени пользователя, переключатели тёмная тема и уведомления (UI; часть настроек может храниться локально).
Язык интерфейса: русский / English (vue-i18n, сохранение в localStorage).
Аватар: выбор изображения с превью и хранение в localStorage (без загрузки файла на сервер).

Темы: светлая и тёмная (нейтральные серые тона, «стеклянные» панели).
